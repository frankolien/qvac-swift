# Changelog

## v0.1.0 — 2026-07-28

The first release: a native Swift client for the QVAC SDK, from wire bytes to
a typed 37-method surface, with every protocol claim verified against the
reference implementation rather than the written brief.

### Wire (`QVACWire`)
- `bare-rpc` frame codec: CompactSize varints, zigzag signed ints, bitmask
  stream flags, error structs. Verified byte-for-byte against **85 vectors
  generated by the reference JS encoder**, covering every varint width
  boundary, the signed errno range, and payload sizes across each
  length-prefix transition.
- Amortized-O(n) `FrameDecoder` reassembly (proven at one-byte chunking) and
  `NDJSONSplitter` with mandatory trailing-record flush.

### Session (`QVACSession`)
- `actor RPCSession`: request multiplexing, a built-in worker life signal
  (transport death fails everything pending immediately — the documented
  `bare-rpc` dead-channel hang, fixed), pull-based `PAUSE`/`RESUME`
  backpressure with hysteresis, and cancellation mapped onto structured
  concurrency (`DESTROY` on consumer cancellation).
- All three call shapes, including duplex request streams with write-side
  flow control (`OPEN`-ack gating, peer corking, `END` half-close).
- `SocketListenerTransport`: `AF_UNIX` and `tcp://`, in the direction the SDK
  actually uses — the client listens, the worker dials in.
- `WorkerProcess` + `QVACClient.launchWorker`: the desktop spawn contract
  (`bare <worker> '{"QVAC_IPC_SOCKET_PATH":...,"HOME_DIR":...}'`) with stderr
  tail capture for crash diagnostics.

### Typed client (`QVACClient` + `qvac-codegen`)
- The full 37-method surface generated from the vendored contract
  (`tetherto/qvac@fadfaedc`): discriminator-peeking unions, varname-driven
  enums, error-code tables, ~13.6k lines of models. Deterministic output;
  name collisions are hard errors; `--check` makes staleness a CI failure.
- Progress promotion done honestly: unary overloads refuse promotable
  requests instead of hanging; `onProgress:` overloads drive the promoted
  stream; hand-written predicates asserted verbatim against the manifest's
  JS condition strings.
- In-band `{"type":"error"}` gate with symbolic code names; watchdog-bounded
  `__shutdown__` roundtrip.

### iOS
- `Extras/WorkletTransport`: a documented drop-in adapting BareKit's worklet
  IPC to the transport seam (copy-in rather than a dependency because
  `bare-kit-swift` links a framework it does not vendor).

### Verification
- 51 tests: protocol fixtures, scripted-transport session invariants, live
  integration against a **real `bare-rpc` peer** over TCP and Unix sockets
  (including duplex and the turnkey spawn path), and generator determinism.
- CI: Linux + macOS full suites plus a codegen staleness gate.
